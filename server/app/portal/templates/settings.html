Thresholds {{ lock('thresholds') }}

Scores from 0 to 1. Cover hides the image on the device and sends the crop; the second opinion then sorts explicit from review. Ask is the lower line where the device blurs first and lets this server decide. Flag equals cover by default; set it lower only to send crops below the line without covering them, which means someone saw them sharp.

From ask up to sure the device blurs the image and asks this server's bigger model; a safe answer unblurs it and nothing is kept. At sure or above it covers and reports without asking. A picture joins the known-bad list, covered everywhere by its fingerprint, only when the second opinion reaches the known-bad line and the picture has enough detail; marking an item a false alarm takes it and its look-alikes off the list.

Coverage {{ lock('coverage') }}

How much skin counts. The classifier judges every image for pornography at the thresholds above; this decides which body parts the detector also covers.

Apps {{ lock('blocked_apps') }}

One identifier per line. Android package names, Windows process names, iOS bundle IDs; each device ignores the ones that are not its own.

Nothing is judged, covered or reported while one of these is in front. Partners see this list in the digest; with locks on, adding to it needs a partner code. Android only for now.
